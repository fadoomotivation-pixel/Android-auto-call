## Full description (max 4000)
SalesAutoCall helps sales teams spend less time dialing and more time talking.

Import a contact list from a CSV or TSV file, then let SalesAutoCall work through
it call after call using your phone's own SIM. Every call is logged
automatically — who you called, when, how long, and the outcome — and synced to
your company's secure cloud so managers can see real productivity, not guesswork.

Key features
• Import contacts from CSV or TSV — automatic column detection
• Sequential auto-dialing through your SIM (dual-SIM aware)
• Automatic call logging: duration, outcome, timestamps
• Cloud sync with per-company data isolation
• Do-Not-Call list is always skipped
• Manager web dashboard for team-wide productivity

Built for business
SalesAutoCall is a B2B tool for a company's own agents. It never records call
audio and never reads your personal contacts or call history. Calling is started
by the agent and can be stopped anytime.

Please use responsibly: only contact people who have consented, and follow your
local telemarketing / Do-Not-Call regulations.
